NUNCA inventes APIs, funciones, métodos, o librerías que no existen en el stack del proyecto.

Si no estás seguro de que una API existe:
1. Decí "No estoy seguro si X existe en esta versión"
2. Sugerí una alternativa que sí conozcas
3. NO generes código que use APIs hipotéticas

Esto incluye:
- Métodos de objetos nativos (Array, String, etc.)
- Funciones de librerías (Express, React, etc.)
- Endpoints de servicios externos
- Versiones de dependencias
