# Nivel 4 — Prompt Library

## Proyecto: Sistema de templates reutilizables

Sistema de prompt library con templates parametrizables, composición de prompts, y CLI para listar, mostrar y renderizar.

### Archivos

- `prompt-library/prompts/` — templates markdown con variables {{variable}}
- `prompt-library/render.js` — motor de renderizado con includes y validación
- `prompt-library/prompt-library.js` — CLI con comandos list, show, render
- `prompt-library/package.json` — dependencias y bin

### Cómo empezar

1. Leé la guía en `docs/level-04-prompt-library.md`
2. Creá los templates iniciales en prompts/
3. Construí el motor de renderizado (render.js)
4. Construí el CLI (prompt-library.js)
5. Probá renderizar templates contra código de niveles anteriores
6. Agregá un template propio
