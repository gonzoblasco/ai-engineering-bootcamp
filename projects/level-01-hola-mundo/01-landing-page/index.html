¿Qué es este roadmap?

Una guía gamificada de 10 niveles para convertirte en un ingeniero especialista en desarrollo asistido por IA.

🎯

Objetivo claro

Preparación para postular como AI-Driven Engineering Specialist — el puesto pide Cursor o Claude Code, pero la metodología es transferible a VS Code + Copilot.

🛠️

Stack moderno

VS Code + GitHub Copilot como entorno principal. Fullstack JS/TS + Node.js, APIs, microservicios, AWS y CI/CD.

🎮

Método gamificado

Cada nivel desbloquea el siguiente. Dificultad progresiva con badges: 🟢 🟡 🟠 🔴 👑. Marca tu progreso y haz self-review al final de cada nivel.

📚
