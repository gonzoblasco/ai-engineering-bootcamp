# Proyecto 1.1 — Landing page personal

> **Nivel:** 1 — Hola Mundo con IA 🟢
> **Dificultad:** Principiante
> **Documentación:** [level-01-hola-mundo.md](../../../docs/level-01-hola-mundo.md)

## Descripción

Crea una landing page HTML/CSS/JS desde cero usando solo Copilot Chat.

## Pasos

1. Abre Copilot Chat (`Cmd+Shift+I` o el ícono de chat)
2. Pídele: *"Crea una landing page personal con HTML, CSS y JavaScript vanilla. Incluye hero section, about, projects y contact form."*
3. Acepta las sugerencias y crea los archivos
4. Itera: pide mejoras de diseño, responsive, animaciones
5. Abre el HTML en el navegador y verifica

## Criterios de completitud

- [ ] Landing page funciona en el navegador
- [ ] Es responsive
- [ ] Usaste al menos 3 prompts diferentes para iterar
- [ ] Pediste una explicación de algún fragmento de código
