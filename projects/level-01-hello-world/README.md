# Nivel 1 — Hello World

## Proyecto: Landing page personal

Creá una landing page personal desde cero usando solo prompts de IA.

### Archivos

- `index.html` — estructura HTML
- `styles.css` — estilos
- `script.js` — interactividad

### Cómo empezar

1. Leé la guía en `docs/level-01-hello-world.md`
2. Usá el chat de tu IA para generar la página
3. Iterá hasta que te guste el resultado
4. Abrí `index.html` en el navegador para verificar
