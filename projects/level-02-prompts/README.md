# Nivel 2 — Prompts que funcionan

## Proyecto: API REST de tareas

API REST para un gestor de tareas, generada y refinada con prompts estructurados.

### Archivos

- `tasks-api/index.js` — entry point con Express, middlewares, rutas y lógica
- `tasks-api/routes/tasks.js` — rutas separadas
- `tasks-api/services/tasksService.js` — lógica de negocio separada
- `tasks-api/package.json` — dependencias

### Cómo empezar

1. Leé la guía en `docs/level-02-prompts.md`
2. Seguí los pasos: prompt vago → prompt estructurado → middleware → paginación → refactor
3. Probá cada endpoint con curl o Postman
4. Compará la diferencia entre un prompt vago y uno estructurado
