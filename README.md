# 🎮 AI Engineering Bootcamp

> 10 niveles para dominar el desarrollo asistido por IA.
> De "aceptar autocomplete" a "orquestar agentes en producción".

## ¿Por qué existe?

La IA cambió cómo se escribe código. Pero la mayoría aprende por prueba y error — sin estructura, sin metodología, sin entender por qué funciona.

Este bootcamp es **mi trabajo práctico**: estoy aprendiendo AI-assisted development de forma sistemática, y compartiendo el camino para que otros puedan seguirlo.

Cada nivel tiene:
- **🧠 Teoría** — el concepto, el porqué, cómo funciona
- **🛠️ Práctica** — un proyecto real que construyo y queda en el repo
- **📣 LinkedIn** — un post que publico mostrando lo que aprendí
