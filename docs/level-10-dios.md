## Proyecto 1: E-commerce API completa

**Descripción:** Sistema completo de e-commerce con todo lo aprendido.

### Alcance

- Microservicios: Auth, Products, Orders, Payments, Inventory, Notifications
- API Gateway
- Event-driven communication (RabbitMQ)
- PostgreSQL + Redis + MongoDB (polyglot persistence)
- JWT auth con refresh tokens
- CI/CD con GitHub Actions
- Tests: unit, integration, E2E
- Security hardening completo
- Performance optimization
- Deploy en AWS con Terraform
- Monitoreo y logging
- Documentación completa (OpenAPI, ADRs, README)

### Reglas

1. **Todo asistido por IA** — usa Copilot para cada componente
2. **Documenta cada decisión** — por qué elegiste X sobre Y
3. **Usa tu prompt library** — demuestra que tus templates funcionan
4. **Aplica tus checklists** — audita el código con tus propios checklists
5. **Mide el tiempo** — cuánto te lleva con IA vs sin IA

### Criterios de completitud

- [ ] 5+ microservicios funcionando
- [ ] CI/CD pipeline completo
- [ ] Test coverage > 70%
- [ ] Security audit pasado
- [ ] Deploy en AWS funcional
- [ ] Documentación completa
- [ ] Docker Compose para desarrollo local
- [ ] Monitoreo básico configurado
