# Level 9 — Team Multiplier 🔶

> **Goal:** Become the AI expert on your team. Learn to mentor others, create team-wide standards, and measure the impact of AI-assisted development.
>
> **Difficulty:** Advanced | **Projects:** 3 | **Estimated time:** 4-5 hours

## Skills you'll gain

- [ ] Create team-wide AI standards
- [ ] Mentor other developers in AI-assisted development
- [ ] Measure AI productivity impact
- [ ] Create onboarding materials
- [ ] Lead AI workflow adoption

---

## Project 1: Team standards document

**Description:** Create a comprehensive team guide for AI-assisted development.

### Steps

1. Ask Copilot: *"Create a team standards document for AI-assisted development. Include: prompt templates, commit conventions, review checklist, and security audit rules."*
2. Add onboarding: *"Add a section for new team members: how to set up Copilot, how to write effective prompts, common pitfalls."*
3. Add workflow diagrams: *"Add Mermaid diagrams showing the team's AI workflow: feature request → prompt → code → review → deploy."*
4. Add FAQ: *"Add a FAQ section addressing common concerns: code quality, security, over-reliance on AI."*

### Completion criteria

- [ ] Document covers all sections
- [ ] Onboarding section is complete
- [ ] Workflow diagrams are clear
- [ ] FAQ addresses real concerns

---

## Project 2: AI productivity dashboard

**Description:** Create a dashboard that measures the impact of AI-assisted development on your team.

### Steps

1. Ask Copilot: *"Create a Node.js script that analyzes git history and measures: commits/day, lines changed, PR cycle time, and build success rate."*
2. Add AI comparison: *"Add a way to compare metrics before and after AI adoption (use a date threshold)."*
3. Add visualization: *"Generate charts showing the trends: commit frequency, cycle time reduction, build success improvement."*
4. Add report: *"Generate a weekly markdown report with key metrics and trends."*

### Completion criteria

- [ ] Script analyzes git history
- [ ] Before/after comparison works
- [ ] Charts are generated
- [ ] Weekly report is produced

---

## Project 3: Mentoring session plan

**Description:** Create a structured plan for mentoring other developers in AI-assisted development.

### Steps

1. Ask Copilot: *"Create a 4-session mentoring plan for teaching AI-assisted development. Each session should be 1 hour with hands-on exercises."*
2. Session 1: *"Session 1: Copilot basics — autocomplete, chat, inline suggestions. Exercise: build a simple API."*
3. Session 2: *"Session 2: Advanced prompts — context, chaining, @workspace. Exercise: refactor legacy code."*
4. Session 3: *"Session 3: Workflows and gates — Pre-Flight, build check, review. Exercise: create a workflow script."*
5. Session 4: *"Session 4: Security audit and CI/CD. Exercise: audit an AI-generated app and set up CI review."*

### Completion criteria

- [ ] 4 sessions with clear objectives
- [ ] Each session has a hands-on exercise
- [ ] Materials are ready to use
- [ ] You could deliver Session 1 today
