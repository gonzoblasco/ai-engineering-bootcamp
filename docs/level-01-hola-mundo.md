# Nivel 1 — Hola Mundo con IA 🟢

> **Objetivo:** Primer contacto. Configurar el entorno y generar tu primera app con IA.
>
> **Dificultad:** Principiante | **Proyectos:** 2 | **Tiempo estimado:** 1-2 horas

## Skills que ganarás

- [ ] Usar Copilot Chat
- [ ] Aceptar inline suggestions (Tab)
- [ ] Usar `@workspace` para contexto
- [ ] Iterar conversacionalmente
- [ ] Pedir explicaciones de código

---

## Proyecto 1: Landing page personal

**Descripción:** Crea una landing page HTML/CSS/JS desde cero usando solo Copilot Chat.

### Pasos

1. Abre Copilot Chat (`Cmd+Shift+I` o el ícono de chat)
2. Pídele: *"Crea una landing page personal con HTML, CSS y JavaScript vanilla. Incluye hero section, about, projects y contact form."*
3. Acepta las sugerencias y crea los archivos
4. Itera: pide mejoras de diseño, responsive, animaciones
5. Abre el HTML en el navegador y verifica

### Criterios de completitud

- [ ] Landing page funciona en el navegador
- [ ] Es responsive
- [ ] Usaste al menos 3 prompts diferentes para iterar
- [ ] Pediste una explicación de algún fragmento de código

---

## Proyecto 2: Generador de contraseñas

**Descripción:** Mini-app web vanilla JS que genera contraseñas seguras.

### Pasos

1. Pídele a Copilot: *"Crea un generador de contraseñas en JavaScript vanilla con opciones de longitud, mayúsculas, números y símbolos."*
2. Implementa la UI con HTML/CSS
3. Pide a Copilot que añada validación y feedback visual
4. Refina: pide que copie al clipboard, que muestre la fortaleza de la contraseña

### Criterios de completitud

- [ ] Genera contraseñas con opciones configurables
- [ ] Copia al clipboard
- [ ] Muestra indicador de fortaleza
- [ ] Refinaste el código con al menos 2 prompts de corrección
